# CS320Mod8RepositoryMOlsey
This is the Journal assignment for Module 8 of Software Test and Automation QA for the CS 320 class.

*How can I ensure that my code, program, or software is functional and secure?*

I can ensure that my code is functional and secure by developing it according to the software requirements and testing 
each requirement thoroughly. In my SNHU projects, I used JUnit tests to verify that the Contact, Task, and Appointment 
services accepted valid information while rejecting invalid values like null fields, incorrect field lengths, or 
invalid dates. I also tested service operations like adding and deleting records to confirm that they behaved as 
expected. Testing both valid and invalid inputs helps identify problems before software is released and reduces the 
possibility of unexpected behavior.

*How do I interpret user needs and incorporate them into a program?*

I interpret the user's needs by first translating the requirements into specific features and rules that can be 
implemented and tested. For example, the requirements for my Contact, Task, and Appointment projects defined constraints 
like maximum field lengths, unique IDs, and acceptable date values. I used these requirements to guide both the program 
code and the JUnit tests.

*How do I approach designing software?*

When designing software, I identify what the program must accomplish, breaking those requirements into smaller classes and
methods, and then determining how the components should interact. I also consider testing during the design process rather 
than waiting until development is finished. This approach makes the software easier to understand, maintain, and verify 
against the user's requirements.
